# 推荐与决策层优化（2026-11 阶段总结）

> 范围：三选一推荐（recommend）、符文联动（synergy）、机制契合（fit）、引擎已持记录（engine）、显示层（overlay / mainwindow / panel）。
> 状态：已实现并全量回归通过（1035 passed, 1 skipped）。已归入 `v1.1.6` 正式发版。

## 背景

代码评审发现推荐与决策层四类问题：

1. **决策缺陷**：三选一关闭时把「推荐首选」当真记录为已持（刷新场景误记）；零数据新海克斯被联动加成推成首选；徽章与判定自相矛盾（「🌟核心·建议刷新」）。
2. **量级失控**：手工联动分（5~8pp）可无界叠加（实测 +19.5pp），碾压实测胜率差（典型 ±3pp）。
3. **适配缺失**：英雄×符文胜率已含英雄适配度，但联动分是全局手工值，不区分英雄——大嘴和琴女拿一样的小蜜蜂联动加成。
4. **依据不可靠**：联动数值来自短视频攻略，版本轮换即过期，也没有推算新组合的能力。

## 设计原则

- **实测数据为主，机制推导为辅**：手工知识只作先验，量级封顶，方向永远让步于实测胜率；数据一多自动失效。
- **不重复计算**：英雄×符文胜率本身包含英雄适配度，机制先验只在样本不足时起作用。
- **不发明数据**：未收录的符文/英雄先验为 0；没有数据的卡不能靠任何手工规则当首选。
- **可解释**：每条加减分都在理由里写明来源和计算过程。

## 已完成的改动

### 1. 决策机制修复

| 问题 | 修复 | 位置 |
|---|---|---|
| 三选一关闭误记「首选已选」，刷新时污染整局联动 | 改为推测记录（`_acquired_guess`），关闭后 10 秒内出现新一组自动撤回；手动点「✔ 选入本局已持」立即转正 | `lolhex/engine.py` |
| 零数据新海克斯被联动救活成首选 | `nodata` 卡只展示联动、不参与打分，理由标注「无数据，不计分」 | `lolhex/recommend.py` |
| 联动分无界叠加（+19.5pp） | 递减叠加（最大组全额 + 其余 30%）+ 封顶 8.0（`COMBO_BONUS_CAP` / `COMBO_STACK_DECAY`） | `lolhex/synergy.py` |
| 徽章/判定两套决策矛盾 | 核心徽章必须实测支撑（Δ ≥ +2.5pp 且 ≥ 400 局）；静态绝活表降级为机制解读文案；徽章用联动加权前分数 + 全体局数口径 | `lolhex/synergy.py` `classify_augment_tier`、`lolhex/recommend.py` |
| 薄样本差卡一律标「可选」 | 样本量只影响首选资格；分数差的薄样本卡照常标「建议刷新」 | `lolhex/recommend.py` |

### 2. 机制契合层（新模块 `lolhex/fit.py`）

- **机制向量**：48 个质变/联动符文标注机制标签（攻击特效、普攻频次、暴击、法强、急速、蓝量、生命、双抗、治疗护盾、近战、吸血、移速、爆发、射程），英雄按 8 个流派（`HERO_ARCHETYPE_MAP`）给机制亲和度。
- **机制先验**：`fit_adjustment` 产出 0 ~ +1.5pp（封顶 `FIT_CAP`），按 `k/(局数+k)` 淡出——等价于把贝叶斯平滑基准从「英雄平均」换成「英雄平均+先验」，只在样本不足时起作用。绝活档案（`DUAL_PLAYSTYLE_PROFILES`）是英雄级覆盖：狗熊是坦克流派，但被动攻击特效契合小蜜蜂，先验拉满。
- **联动门控**：`combo_gate` 把联动分按候选符文与本英雄的契合度折算（30% ~ 100%）。实测效果：小蜜蜂×大嘴先验 +1.50pp、门控 ×1.00；琴女 +0.08pp、×0.34。
- **「几乎不选」兜底**：固定 -3.0 改为 `机制先验 + 全服Δ×50%` 折算（`global_fit`），只减不加分（上限 -0.2、下限 -3.0），且有实测候选时不进首选池。
- **同稀有度排名**：改用平滑胜率 + ≥250 局门槛（与样本分档对齐），3 局 100% 不再排第一。
- **面板一致**：`panel.py` 的 Δ 与三选一分数同口径（共用 `apply_fit`）。

### 3. 联动算分机制化（替代攻略视频手工值）

```
联动分 = 交互类型基础分 × 机制耦合度
```

- **交互类型**（`INTERACTION_BASE`）：乘算 6.0（珠光×易损）> 频次放大 5.5（小蜜蜂×双刀流）> 资源转化 5.0（超凡×尤里卡）> 线性叠加 2.5（双巨人堆血）。量级锚定实测 Δ。
- **机制耦合度**：两符文机制向量共享维度按 min 权重求和（满耦合 ≥1.0）。人工确认有交互但模型未覆盖的组合按 0.5 档计（`CURATED_COUPLING_FLOOR`）。
- **手工表只留「有什么交互」**：名称、描述、必出装备；交互类型集中在 `COMBO_TYPES`，旧 bonus 字段仅留档。
- **表外组合自动推算**：共享耦合 ≥0.4 即给推算分，封顶 3.0（`GENERIC_CAP`）、标注「推算」；已判冲突的对不再推算正联动。
- **校准结果**：新值分布 1.0 ~ 6.0（均值 3.77）。虚高组合回归：叠角龙×钢化你心 7.5→2.5、万血双巨人 7.0→2.5；真乘算保持高位：珠光×易损 7.5→6.0、小蜜蜂×双刀流 8.0→5.5。
